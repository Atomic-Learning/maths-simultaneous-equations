In a system of simultaneous equations, there are multiple unknown variables, and the goal is to find values that satisfy all equations at the same time.

# Example

For example, consider the following system of equations:

$$
x + y = 5\\
2x - y = 1
$$

The solution to this system is $x = 2$ and $y = 3$, as these values satisfy both equations simultaneously.

# Number of Solutions

A system of simultaneous equations can have:

- **A unique solution**: There is exactly one set of values for the unknowns that satisfies all equations.
- **No solution**: There is no set of values for the unknowns that satisfies all equations simultaneously.
- **Infinitely many solutions**: There are multiple sets of values for the unknowns that satisfy all equations.

# Linear vs Non-Linear Systems

A system of simultaneous equations can be classified as either linear or non-linear. This distinction is important because these systems behave differently and are typically solved using different techniques.

## Linear systems
All equations in the system are linear, meaning that the variables appear only to the first power, and there are no products of variables. For example:

$$
x + y = 5\\
2x - y = 1
$$

## Non-linear systems
At least one equation is non-linear, meaning it contains terms that are not linear, such as products of variables, powers greater than one, or other non-linear functions. For example:

$$
x^2 + xy + y = 5\\
2x - y = 1
$$

# Solving Simultaneous Equations

There are several methods of solving simultaneous equations. Which is most appropriate depends on the properties of the system.
